# Sim-and-Real Co-Training 精读

- **论文**：Sim-and-Real Co-Training: A Simple Recipe for Vision-Based Robotic Manipulation
- **作者**：Maddukuri, Jiang, Chen, Nasiriany 等（UT Austin、NVIDIA、UC Berkeley），项目负责人 Mandlekar、Fan、Zhu
- **链接**：[arXiv 2503.24361](https://arxiv.org/abs/2503.24361) · [项目](https://co-training.github.io)
- **发表处**：预印本（arXiv v2，2025-04-02，comment 字段未写会议）
- **在本方向的位置**：sim + real 共训练的基线配方，后续工作（MetaGenSim、SARI、R2S2R Grounding、RL-Co 等）多以它为对照

## 1. 问题

真实示教少（每任务 20–50 条），仿真可以低成本生成大量轨迹。论文研究：仿真数据与真实任务要对齐到什么程度、按什么比例混合，才能提升真机成功率。论文不追求零样本 sim-to-real，而是把仿真数据和真实数据放进同一个模仿学习损失里。

## 2. 方法

### 2.1 损失与采样

$$L_{total}(\theta) = \alpha \cdot L(\theta; D_{sim}) + (1-\alpha) \cdot L(\theta; D_{real})$$

- α 是每个 batch 中样本来自仿真的概率，实现方式是按数据集大小归一化每个样本的权重后，仿真样本乘 α、真实样本乘 1−α。
- 策略：Diffusion Policy。Panda 用 CLIP 语言编码 + FiLM，默认 α=0.9；GR-1 用 UMI 版 DP（ViT 编码器 + UNet），默认 α=0.99。
- 不用域对抗、不加域标签，也不做图像翻译；两个域共用同一个网络和动作空间。

### 2.2 两种仿真数据

- **Prior（任务无关）**：事先存在的多任务仿真数据。Panda 用 RoboCasa 的 60k 条示教（20 个任务，每任务 50 条人类示教经 MimicGen 扩增到 3,000 条）；GR-1 用 10 个 RoboCasa 抓放任务，每任务 1,000 条，共 10k。与真实任务在物体类别、纹理、物理参数、初始位姿上都有差异，只把相机重新渲染到接近真实视角。
- **DC（task-aware digital cousin）**：为真实任务专门搭的仿真，保留四个要素：
  1. 相同的机器人与动作空间；
  2. 相同的任务目标（成功判定、语言指令）；
  3. 相同的物体类别，具体实例可以不同；
  4. 相同的固定设施类别（台面、柜门等）。
- DC 的搭建：对齐机器人初始位姿与相机位置；物体从同类别中随机抽取以增加多样性；Panda 每任务 100 条源示教 → MimicGen 10,000 条，GR-1 每任务 10 条源示教 → DexMimicGen 1,000 条。

### 2.3 数据组成因子

论文把 sim 与 real 的差异拆成六个因子：任务组成、场景组成、物体组成、初始状态分布、相机参数、动力学参数。实验逐个改变其中几个，观察真机成功率。

## 3. 关键结果

### 3.1 主结果（Table I，真机成功率）

| 数据组成 | 6 任务平均 |
|---|---|
| Real | 45.3% |
| Real + DC | 81.1% |
| Real + Prior | 76.8% |
| Real + DC + Prior | 83.2% |

- 真实示教：Panda 每任务 50 条，GR-1 每任务 20 条。
- CloseDoor：Real 10%，任一共训练配置 100%。把纯真实示教加到 100 条，Real 也只有 80%（附录 L）。

### 3.2 泛化（Table II）

- 未见物体：Panda 33% → 50%，GR-1 10% → 80%（Real → Real + DC）。
- 未见位置（真实示教刻意不覆盖工作区中部，仿真均匀覆盖）：Panda 11% → 28%，GR-1 43% → 100%。

### 3.3 设计因子的消融

- **仿真数据量**：Panda C2SPnP 的 DC 从 10k 减到 500，67% → 53%；GR-1 CupPnP 从 1k 减到 100，95% → 75%。
- **混合比 α**（CupPnP，20 real + 1,000 DC）：1:1 不是最优；0.9 与 0.99 最好；α 提到 0.995、0.999 时成功率从 95% 降到 60%。
- **相机对齐**：用默认未对齐视角渲染 DC，Panda 67% → 56%，GR-1 95% → 70%。默认视角与对齐视角相差约 36–37 cm、20–60°；对齐后的仿真相机仍没有模拟真实头部相机的鱼眼畸变。
- **真实数据变多**（MultiTaskPnP，4,000 DC，在未见物体上评测）：真实示教从 40 增加到 400 条，共训练始终高于纯真实，读图约为 38% vs 17%、89% vs 39%。
- **数据比例表**（附录 Table VI，CupPnP）：
  - 固定 20 real，仿真 20/100/200/500/1,000 条：48/73/85/88/95%。
  - 固定 1,000 sim，真实 1/5/10/20/50 条：8/40/73/95/95%。
- **视觉逼真度**：用在真实视频上微调的 CogVideoX 做 Vid2Vid，噪声强度 0.6。平均提升 5–10%，数据少时收益最大，例如 20 real + 20 sim：48% → 70%；数据充足时两者都是 95%。
- **动力学对齐**：在 GR-1 CupPnP 上调物理参数缩小开环回放差距，成功率有无对齐都是 95%，论文结论是"对我们的任务不必要"。
- **行为模式必须一致**：GR-1 BimanualPnP 中，50 real 为 15%，加 1,000 DC 为 50%，100 real 为 30%；但与只有单臂抓放的 Prior 共训练（α=0.99）时，策略学成单臂抓放，成功率接近 0。

## 4. 论文给出的配方

1. 优先构建 task-aware digital cousin：任务定义和成功判定与真实一致，相机视角大致对齐；不追求精确孪生。
2. 仿真中让物体和摆放位置更多样，覆盖真实示教没覆盖的情况。
3. 仿真数据量比真实多几个数量级；混合比需要调，CupPnP 上 0.9–0.99 最好，过高会掉。
4. 任务无关的 Prior 数据也有帮助，但其中的行为模式要和真实任务一致。
5. 域随机化、生成式纹理、Vid2Vid 是补充手段，不是必要条件。

## 5. 自述局限

- 任务以抓放为主；高精度插装、长时程任务留作未来工作。
- 成功率仍未到 100%。
- 可变形物体、液体难以仿真，限制了仿真数据的适用面；建议探索视频生成模型和世界模型生成共训练数据。

## 6. 与"精确孪生 + 少量遥操作"设定的对照

- 论文的 DC 只对齐语义、相机和初始位姿，比精确孪生粗；论文没有测"精确孪生 vs digital cousin"的差别。real2sim 方向中 ACDC 报告表亲分布比精确孪生零样本迁移更好（90% vs 25%），见 [real2sim 综述 §2.2](../../real2sim/survey.md)。
- 动力学对齐无效的结论只在 GR-1 CupPnP 这类准静态抓放任务上测过；接触任务的结论见 Sim&Real Pushing（物理保真比视觉保真更重要），见 [vla-fast-control 综述 §4.2](../../vla-fast-control/survey.md)。
- 论文中的 α 针对单一策略、单一任务调出；多任务、多仿真源的混合比如何设置，论文没有给出方法。
