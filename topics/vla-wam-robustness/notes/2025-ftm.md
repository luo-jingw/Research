# FTM / FLA 精读

- **论文**：VLA Models Are More Generalizable Than You Think: Revisiting Physical and Spatial Modeling
- **作者**：Weiqi Li, Quande Zhang, Ruifeng Zhai, Liang Lin, Guangrun Wang（中山大学；X-Era AI Lab）
- **链接**：[arXiv 2512.02902](https://arxiv.org/abs/2512.02902)；abs 页上没有代码或项目页
- **版本**：v1 2025-12-02，v2 2026-03-31。本笔记按 v2，和 v1 不同的地方单独注明。
- **发表处**：CVPR 2026。依据是 openaccess.thecvf.com 的 CVPR 2026 列表页（paper.html、paper.pdf、supplemental.pdf 三项），以及 cvpr.thecvf.com/virtual/2026/poster/39351（Poster，2026-06-07）。arXiv 的 comment 字段为空。
- **在本方向的位置**：冻结 VLA、只改视觉侧的少参数视角适应。DART、VLA-ZO 以 FLA 为基线；DART 还在锚点协议下独立复现了 FLA。见 [综述 §3](../survey.md)。

下文"推断"标出的是读者的判断，不是论文原话。

## 1. 论点（引言、§3）

- 论文把 VLA 分成两部分：Spatial Modeling（视觉编码器）和 Physical Modeling（VLM 加动作专家）。
- 论点：视角漂移主要扭曲的是视觉嵌入，动作侧仍然可用，所以只做轻量的视觉侧适应就够了。原文的说法是，退化来自 "misalignment in Spatial Modeling, rather than Physical Modeling"。
- 附录 §8 给了一个 Lipschitz 上界的论证，依赖三个假设：
  - A1：策略局部 Lipschitz；
  - A2：任务语义不变；
  - A3：目标域到源域的 token 映射近似仿射或低秩。
  - 论文说这些假设 "mild and can be empirically verified"，但没有给出验证。
- 附录 §9 用 t-SNE 展示适应前后的视觉 token 分布：FLA 之后，目标域分布"紧邻"源域流形，但两者不重合。

## 2. 方法

### 2.1 FTM（§3.3）

- 形式：F̂ = (1+γ)⊙F + β。其中 F ∈ R^{N×D_ViT}，γ、β ∈ R^{D_ViT}，D_ViT = 2048，共 2×2048 ≈ 4K 个参数。
- γ、β 是全局参数，不随输入变化；主干全部冻结。
- 推断：π0.5 的 SigLIP So400m 宽度是 1152，2048 是投影到 Gemma 之后的宽度，所以 FTM 实际作用在投影后的图像 token 上。
- 文中没有说明腕部相机和第三人称相机两路是否共用同一组 γ、β。
- Fig. 4a 有一个"只在训练时使用、推理时移除"的虚线框，正文没有解释。

### 2.2 FLA（§3.4）

- 在 SigLIP ViT 的线性层（共 27 层）上加 LoRA（ΔW = BA）。rank 16 对应 4.7M 参数，rank 32 对应 9.4M。
- 语言模型和动作专家冻结。不用 EMA，用 float32 训练（§12）。

### 2.3 训练设置（§4.3，Table 7）

- 单张 A100，batch 32，输入 224×224，两路相机（腕部加第三人称）。
- FTM：训练 5,000 iter，峰值学习率 5e-4。
- FLA：§4.3 写"LoRA 和 FLA 都训 2000 步"，Table 7 写 1,500 iter（decay 2,000），两处不一致。

### 2.4 基线（§4.2，§12）

- π0 / π0.5 的一次演示 LoRA：VLM rank 16，动作专家 rank 32，约 467M 参数。
- 替换视觉骨干（GeoAware 式）：冻结 VGGT，加可训练投影。
- 提示学习：PaliGemma 宽度的前缀 token，加动作专家宽度的后缀 token；只训练提示和动作头，共 0.131M 参数。
- OpenVLA-OFT，以及在 LIBERO-Plus 上微调过的 OFT-m。

### 2.5 真机（§7）

- Franka Panda，用 GELLO 采集，5 个任务。在新视角下用 1 条演示做 FLA（rank 32，750 步，batch 32）。
- 结果只有定性的 Fig. 7，外加一句"用不完美演示适应时 FLA 达到 90.7%"（§7.4），没有说明试验次数和协议。

## 3. 评测口径

### 3.1 LIBERO 新视角

- 四个套件（Spatial / Object / Goal / Long）各 10 个任务，新视角下每个任务 50 次试验（§4.1，沿用 Adapt3R）。
- 只移动第三人称的 agentview 相机，腕部相机不动。

### 3.2 视角幅度

- 原文（§10.1.1，v1 为 9.1.1）只定义了两种模式，没有给出数值：
  - 连续轨道：绕末端执行器在 xy 平面上按半径旋转 θ，朝向复合 R_z(θ)；
  - 离散三档 S/M/L：每档"施加固定平移偏移 Δp 和特定四元数旋转"，沿用 Adapt3R。
  - Fig. 11 只有柱状图。v1、v2 和 CVPR 补充材料 PDF 里都没有数值。
- **推断**：三档的幅度就是下面两处给出的数值。
  - Adapt3R 附录 C.1 的平移偏移：Small (0.0, +0.3, −0.1) m，Medium (−0.2, +0.7, −0.2) m，Large (−1.2, +1.0, −0.2) m。平移之后，相机重新对准末端执行器的起始位置。
  - DART 附录 0.C.2 写明 "following prior work [Adapt3R, FLA]"，给出同样的三组偏移；Table 12 列出各场景的旋转角：Small 18.5–33.2°，Medium 45.1–69.7°，Large 106.9–126.6°。
  - 依据：DART 在这套协议下复现 FLA，得到 91.6；锚点报告的是 90.8（DART Table 10）。这是高置信度的推断，不是锚点原文。
- 按上面的数值，Large 档相当于把相机移到桌子另一侧（平移 −1.2 m / +1.0 m，旋转 100° 以上），已经远远超出"相机被碰歪"的程度。

### 3.3 Libero-V 的其他扰动（§10.1.2–10.1.4）

- 光照：漫反射颜色、光照方向、高光、阴影开关，取自 LIBERO-Plus 的管线。
- 纹理：地面和墙面的 PBR 材质（木、石、金属、陶瓷、织物）。
- 传感器噪声：运动模糊、高斯模糊（σ ∈ [1, 10]）、缩放模糊、雾、玻璃模糊，各 10 级。
- 除高斯模糊的 σ 以外，没有给出数值范围；文中也没有说明 Table 3 用的是哪一级。

### 3.4 一次演示

- 每个任务 1 条新域人类演示（§4.1），LIBERO 上共 40 条；适应后在同一批任务上测试。
- DART 改成每个场景 1 条（共 5 条），在 40 个任务上测试，FLA 从 90.8 降到 74.3（Large 只剩 54.3），一次全参微调只有 31.5（DART Table 1）。

### 3.5 混用了其他论文的结果

- Table 1 的 GeoAware-VLA 两行标明"取自原论文"。
- Table 3 噪声一列中，OpenVLA-OFT、OFT-m、π0 三项标 *，取自 LIBERO-Plus。
- 推断：Table 1 的 OpenVLA-OFT 行（90.0 / 15.7 / 81.7 / 13.7）与 GeoAware-VLA 原文 Table I 中 OpenVLA-OFT 的未见视角行逐项相同（均值 50.3 对 50.2），可能也取自 GeoAware，但没有注明。
- GeoAware 原文只报告三个未见视角的平均，正文没有给幅度。锚点 Table 2 把 GeoAware 拆成 S/M/L（88.0 / 74.5 / 71.2，均值 77.9），拆分的来源没有说明。

## 5. 自述局限

- 论文没有局限或未来工作一节。
- 唯一相关的说法：§12 称 FLA 的成功率进入平台期、没有灾难性过拟合；§13 讨论了 rank 容量。

## 6. 读后问题（推断，不是论文原话）

1. 视角幅度没有写，见 3.2。
2. "一次演示"是逐任务校准，换成按场景的协议后明显变差（DART，见 3.4）。
3. 只移动第三人称相机，腕部视图保持不变。腕部视图可能是一条捷径：Cross-View AC 为此全程遮蔽腕部，CoRe-VLA 报告外部相机移位后策略过度依赖腕部，SCVC 的审计显示 Cosmos Policy 遮掉腕部后相机维度只剩 0.2%。锚点没有做遮蔽腕部的对照。
4. 非相机扰动下零样本已经接近饱和，所以"FTM 也能纠正光照或噪声"这一点在论文里没有被真正检验。
5. 真机只有定性结果。
6. §3.1 把 π0.5 写成"自回归输出离散动作 token"，附录 §11 又写成 flow matching 动作专家，前后不一致。
7. 没有报告视觉调优在其他扰动维度上的副作用；VLA-Retain 发现在相机数据上调视觉模块，多数配置会让非目标维度变差。

## 7. 与本方向其他工作的对照

- **独立复现**：DART 按锚点协议复现 FLA 得到 91.6（Table 10），按每场景一条的协议为 74.3（Table 1）。VLA-ZO 用零阶优化重实现的 FLA 为 56.56。见 [综述 §3.5](../survey.md)。
- **视觉侧还是动作侧**：VLA-ZO 在同样的 S/M/L、5 条演示下，动作侧适应（58.2）略好于视觉侧（56.6）（Fig. 2b）。Not All Layers 在五个架构上发现外观漂移的适应代价集中在视觉编码器。见 [综述 §3.2](../survey.md)。
- **不需要演示、需要几何信息的图像侧方法**：AnyCamVLA、GS-VLA、Homeward、CoRe-VLA。本轮没有找到在同一协议下把它们与 FTM 直接比较的论文。见 [综述 §3.3](../survey.md)。
- **未适应数字的口径**：π0.5 在同类 S/M/L 协议下的未适应成功率，FTM 报告 48.5，DART 报告 54.5，VLA-ZO 报告 48.27。见 [综述 §3.6](../survey.md)。
